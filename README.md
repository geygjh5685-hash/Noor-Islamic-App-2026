# نور الإسلامي — Flutter starter

مشروع بداية قابل للتشغيل والتوسعة على Android وiOS.

## المتطلبات
- Flutter SDK حديث (3.22 أو أحدث موصى به)
- Android Studio أو VS Code
- Xcode على macOS لبناء نسخة iOS

## التشغيل
```bash
flutter doctor
flutter pub get
flutter run
```

## بناء APK
```bash
flutter build apk --release
```
المسار الناتج:
`build/app/outputs/flutter-apk/app-release.apk`

## بناء iOS
على macOS فقط:
```bash
flutter build ios --release
```

## ما يعمل حالياً
- واجهة عربية RTL مع تنقل بين الأقسام.
- الصفحة الرئيسية وبطاقات الوصول السريع.
- قائمة سور أولية (أسماء فقط).
- أذكار تجريبية مختصرة ومسبحة تحفظ عدد التسبيحات محلياً.
- مسابقة معلومات إسلامية تجريبية.
- مكتبة تصنيفية أولية.
- إعداد الوضع الليلي محفوظاً على الجهاز.

## مهم قبل النشر
هذه نسخة تأسيسية (MVP) وليست إصداراً دينياً نهائياً. لا تحتوي بعد على نص القرآن كاملاً، أو مواقيت صلاة محسوبة، أو أذان، أو اتجاه قبلة، أو بث صوتي، أو خادم، أو مساعد ذكاء اصطناعي، أو لوحة إدارة. لا تستخدم النصوص التجريبية كمرجع شرعي قبل مراجعتها وتوثيقها.

### الخطوات التالية
1. دمج مصدر قرآن موثوق بالرسم العثماني مع مراجعة المطابقة.
2. إضافة قاعدة بيانات للأحاديث والأذكار مع التخريج.
3. احتساب مواقيت الصلاة وفق طريقة حساب يختارها المستخدم وموقعه.
4. إضافة القبلة والصوت والتنزيلات وإدارة التخزين دون اتصال.
5. بناء API آمن للمساعد الذكي، مع حفظ مفاتيح المزود على الخادم.
6. إضافة اختبارات آلية واختبار أجهزة فعلية قبل النشر.
